Status/label pill. Pick the hue by meaning: `green` = active/approved, `red` = rejected/expired, `amber` = pending/warning, `sky`/`primary` = informational, `violet` = category, `gray` = neutral/default.

```jsx
<Badge variant="green" dot>Đang làm việc</Badge>
<Badge variant="amber" dot>Chờ duyệt</Badge>
<Badge variant="gray">HĐ-2024-118</Badge>
```

Always uppercase-free label text; the mono font + `tabular-nums` suit codes and counts.
